=================================================================
  CUÁNDO USAR CADA ESTRATEGIA
=================================================================

  ESTRATEGIA 1 — Timeouts Individuales
  ────────────────────────────────────
  ✓ Cuando cada endpoint tiene SLAs distintos
  ✓ Cuando es aceptable que algunos datos falten
  ✓ Cuando los endpoints son independientes entre sí
  ✗ No usar si todos los datos son obligatorios

  ESTRATEGIA 2 — Cancelación en Cadena
  ─────────────────────────────────────
  ✓ Cuando hay una condición de "fallo total" (ej. 401)
  ✓ Para ahorrar recursos cuando no tiene sentido continuar
  ✓ Cuando la sesión del usuario controla todos los endpoints
  ✗ No usar si los endpoints son públicos (sin auth)

  ESTRATEGIA 3 — Carga con Prioridad
  ────────────────────────────────────
  ✓ Para UX progresiva: mostrar datos cuanto antes
  ✓ Cuando hay datos "críticos" (productos+perfil) y "secundarios" (categorias+notif)
  ✓ En aplicaciones donde la percepción de velocidad importa
  ✗ Más compleja de implementar y depurar que gather()
